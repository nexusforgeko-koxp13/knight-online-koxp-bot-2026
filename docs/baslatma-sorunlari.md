# Knight Online KOXP başlatma sorunları

Bu rehber, NexusForgeKO launcher üzerinde hatanın hangi aşamada oluştuğunu belirlemek içindir. Bir kontrolün başarılı olması tüm ürün özelliklerinin çalıştığını kanıtlamaz.

| Belirti | İlk kontrol | Sonraki adım |
|---|---|---|
| Uygulama hiç açılmıyor | ZIP çıkarılmış mı, Windows hata metni ne? | Hata metnini ve sistem türünü kaydedin |
| Klasör ekranında exe görünmüyor | Dosyayı Windows Gezgini'nde arayın | KnightOnLine.exe dosyasını içeren klasörü seçin |
| Klasör işaretli, lisans var, düğme yok | Tam pencere ve ekran ölçeği | Pencereyi büyütün; tüm ürün kartını kontrol edin |
| Düğme var, oyun başlamıyor | Resmî oyun launcher'ı tek başına çalışıyor mu? | Oyun hatasını ürün hatasından ayırın |
| Kredi var, aktif süre yok | İlgili ürün için lisans alınmış mı? | Bakiye yükleme ile lisans satın almayı ayırın |

## Sıralı kontrol

1. Kullandığınız sunucuyu ve istemciyi not edin: NTTGame USKO, SteamKO ve özel sunucular aynı kurulum değildir.
2. NexusForge'u kapatıp resmî oyun launcher'ındaki güncellemeyi tamamlayın. Oyunun tek başına açılıp açılmadığını kontrol edin, ardından kapatın.
3. NexusForge'u ZIP penceresinden değil, çıkardığınız klasördeki uygulamadan açın. Varsa güncellemenin tamamlanmasını bekleyin.
4. Doğru oyun klasörünü seçin. Klasör seçim penceresi exe dosyalarını gizleyebilir; dosyanın varlığını Windows Gezgini'nden kontrol edin.
5. Lisansın göründüğü pencereyi büyütün. Yüksek ekran ölçeğinde düğme taşması ihtimalini kontrol etmek için geçici %100 ölçek denenebilir; ardından önceki ayara dönün.
6. Sorun sürerse ekran görüntüsü, hata metni, Windows sürümü ve denenen adımlarla destek isteyin. Aktif lisans varken yeni ödeme yapmak teknik çözüm değildir.
